# UniLife OS 设计系统

> 第二期重构 R8 阶段产物。指导后续 R8-T2 ~ R8-T5 的视觉重构。
> 起草时间：2026-04-25。

## 0. 设计目标与基调

**核心目标**：让 UniLife OS 在赛道里"第一眼不一样"——拥有现代消费级 AI 产品应有的**高级感（premium feel）**，而不是又一个紫色渐变 Streamlit 模板。

**风格基调**：高级平面设计为主，构成主义结构感为辅。

具体而言：
- **平面设计语言**为主：克制的色彩 / 精确的字体层级 / 大块负空间 / 强对比 / 几何块面 / 不依赖装饰元素。这是"高级感"的底层语法。
- **构成主义启发**为辅：保留它的"硬边、强分隔、不对称留白、底部强调线"等结构手法，让视觉有识别度，但**不教条**——不需要严格的红黑黄三色体系，不需要刻意的工业海报感。
- **温度保留**：底色用米色 off-white 而非冷白；按钮交互保留情绪反馈；emoji 在功能场景仍可使用。学生用户每天打开，纯黑白会显得冷峻。

### 高级感的来源（评判每个改动是否"高级"的清单）

1. **克制**：能用 3 个色就不用 5 个；能用一根分隔线就不用阴影。
2. **精致**：字体层级清晰（display ↔ body ≥ 2.4×），间距严格走 8px 网格。
3. **理性**：每个元素都有功能依据，没有"为了好看而加"的装饰。
4. **呼吸**：留白比内容更重要，密集编排是平价感的来源。
5. **稳定**：圆角统一、边框统一、按钮形状统一，避免视觉碎片化。

## 1. 色板（Color Tokens）

色板分两层：**品牌层**（决定整体气质）+ **语义层**（功能反馈）。

### 1.1 品牌层（用于 Header / 主按钮 / Tab 标记 / 链接）

```css
--color-bg-primary:  #F5F2EC   /* 米色 off-white，全局 body / .stApp */
--color-bg-surface:  #FFFFFF   /* 卡片 / Metric / Expander 底 */
--color-bg-emphasis: #1A1A1A   /* Header / 主按钮的近黑（比纯黑温和） */
--color-bg-muted:    #ECE9E2   /* 二级背景 / hover 态 */

--color-text-primary: #1A1A1A
--color-text-muted:   #6B6B6B
--color-text-inverse: #F5F2EC

--color-brand:        #8B2727  /* 品牌主色：深酒红，比 vibrant red 内敛精致 */
--color-brand-soft:   #C24747  /* 品牌主色 hover / 浅化变体 */
```

> 选 **深酒红 #8B2727** 而非 vibrant red：保留构成主义的红色文化基因，但成熟度更高，适合长期阅读。如最终视觉走查觉得偏暗，可上调到 `#A03333`。

### 1.2 语义层（severity / 功能性颜色）

```css
--color-severity-high:   #D62828   /* 紧急告警，必须高识别 */
--color-severity-medium: #F77F00   /* 中级提醒 */
--color-severity-low:    #2A9D8F   /* 低优先 / 完成态 */

--color-data-1:          #1D3557   /* 数据可视化主色：深海蓝 */
--color-data-2:          #8B2727   /* 数据可视化副色：与品牌一致 */
--color-data-3:          #C68B4A   /* 数据可视化第三色：暖琥珀 */
```

> 品牌色与 severity-high 都偏红但有区分：品牌色 `#8B2727` 用于"我是 UniLife"的身份标识，severity-high `#D62828` 用于"现在有事"的告警动作。前者饱和度低更内敛，后者饱和度高更醒目。

### 1.3 边框

```css
--color-border-hairline: rgba(26, 26, 26, 0.10)   /* 默认 1px 分隔 */
--color-border-strong:   rgba(26, 26, 26, 0.85)   /* 模块间 2px 强分隔 */
--color-border-focus:    var(--color-brand)       /* 输入框 focus */
```

## 2. 字体栈（Typography）

```css
--font-display: "Inter", "Geist", "PingFang SC", "Microsoft YaHei", -apple-system, sans-serif;
--font-body:    "Inter", "Geist", "PingFang SC", "Microsoft YaHei", -apple-system, sans-serif;
/* 同栈，仅字重和字号区分；不使用 italic */
```

字重档位（克制使用）：
- 700（display 标题、强调） — 仅在 Header 主标题与 H2 使用
- 600（H3 / 按钮 / Metric 数字）
- 500（强调正文 / 表头）
- 400（正文 / caption / 链接）

> 不使用 800 极粗字重——过粗在中文字体下显得"用力过猛"，违和高级感。

## 3. 字号尺度（Type Scale）

4 级跳跃，display 与 body 比例 ≈ 2.1×（比初版的 2.4× 更克制）：

```css
--fs-display:  2.0rem   (32px)   /* font-weight: 700, line-height: 1.2 */
--fs-h2:       1.4rem   (22.4px) /* font-weight: 700, line-height: 1.25 */
--fs-h3:       1.05rem  (16.8px) /* font-weight: 600, line-height: 1.35 */
--fs-body:     0.95rem  (15.2px) /* font-weight: 400, line-height: 1.55 */
--fs-caption:  0.8rem   (12.8px) /* font-weight: 400, color: muted */
```

字间距：
- 模块标题（uppercase）：`letter-spacing: 0.08em`（让大写字母气质更精致）
- 普通中文：默认 0
- Display 中文：`letter-spacing: 0.02em`（轻微展宽，让大标题更稳）

## 4. 间距尺度（Spacing）

8px 网格，严格走基数：

```css
--space-1: 4px     /* 紧贴元素之间 */
--space-2: 8px     /* 内文行间 / 小元素间距 */
--space-3: 16px    /* 卡片内 padding */
--space-4: 24px    /* 卡片之间间距 */
--space-5: 32px    /* 章节间距 */
--space-6: 48px    /* 大区块分隔 */
--space-7: 64px    /* 章节标题前后 */
```

**留白原则**：宁多勿少。卡片之间用 `--space-4`，章节用 `--space-5`，大区块用 `--space-6`。

## 5. 圆角（Radius）

```css
--radius-none: 0px   /* Header / Tab 强调线 */
--radius-sm:   2px   /* 默认卡片 / Alert / Metric / Expander */
--radius-md:   4px   /* 输入框 / 按钮 */
--radius-lg:   8px   /* 仅当真的需要"软"的元素，如 chat message */
```

> 不再使用 ≥ 10px 的圆角。圆角太大显得卡通，违和高级感。

## 6. 边框（Border）

```css
--border-hairline:  1px solid var(--color-border-hairline)
--border-strong:    2px solid var(--color-border-strong)
--border-severity:  4px solid <severity color>            /* Alert 卡片左强调条 */
--border-tab:       3px solid var(--color-brand)          /* Tab 选中底部 */
--border-focus:     2px solid var(--color-border-focus)   /* 输入框 focus 态 */
```

## 7. 阴影（Shadow）

默认**几乎不用**阴影。仅以下场景：

```css
--shadow-modal:        0 8px 24px rgba(26, 26, 26, 0.10)   /* 浮层 / dialog */
--shadow-button-hover: 0 2px 8px rgba(139, 39, 39, 0.15)   /* 主按钮 hover 时的品牌色光晕 */
```

不用毛玻璃 / 多层阴影 / 渐变阴影。

## 8. 组件视觉规范

### 8.1 Header

```text
After（米底 + 黑块 Header + 左竖品牌色条）
┃                              ↑ 4px 品牌色 #8B2727 左竖条
┃ 🎓 UniLife OS                 display 32px / 700，米色字
┃ 你的大学生活智能操作系统      body 15.2px / 400，米色 60% 透明
┃
```

- 背景 `--color-bg-emphasis` (#1A1A1A) 而非纯黑，更柔和
- 圆角 0
- 内 padding：上下 `--space-3`，左右 `--space-4`
- 左侧 4px 品牌色竖条（构成主义结构标记，但克制为 4px 而非 5px）

### 8.2 Alert 卡片

```text
┃▎🔴 预算告警                        ← 标题 H3 size，severity 色
┃▎本月已花 ¥1900 / ¥2000，剩 5 天   ← body
┃▎  💡 建议日限 ¥20                  ← caption muted
┃▎  [标为已读]                       ← 次按钮
```

- 白底 `--color-bg-surface`
- 左侧 4px severity 色强调条（`--border-severity`）
- 圆角 2px
- 上下 `--space-3` padding，左 `--space-4` padding（避开强调条）
- 标题字号 H3，严重度色；正文 body 主色；caption muted 色

### 8.3 Metric（侧边栏指标卡）

```text
┌─────────────┐
│ 步数        │  ← caption size，muted
│ 8,234       │  ← H2 size，700 重，主色
│ 目标 10,000 │  ← caption muted
└─────────────┘
```

- 白底 + `--border-hairline`
- 圆角 2px
- padding `--space-3`
- 数字用 `--fs-h2` + 700，是 Metric 的视觉主体

### 8.4 Tab 导航

```text
💬 AI 对话    📊 数据看板
━━━━━━━━━━

← 选中态：字重 700 + 底部 3px 品牌色横条 + 字色 primary
← 未选态：字重 500 + 字色 muted + 无装饰
```

- 不要胶囊背景
- 不要圆角
- 仅靠字重 + 底部红条区分选中

### 8.5 按钮三级

```text
主按钮（保存/记录）    次按钮（标为已读）        危险按钮（重置）
┏━━━━━━━━━┓             ┌───────────┐               ┏━━━━━━━━━━━┓
┃ 📝 记录  ┃             │  标为已读  │              ┃ 🧹 重置   ┃
┗━━━━━━━━━┛             └───────────┘               ┗━━━━━━━━━━━┛
背景 emphasis (#1A1A1A)  透明 + hairline border       背景 severity-high (#D62828)
字 inverse (米)           字 primary                    字白
圆角 4px                  圆角 4px                      圆角 4px
hover：背景变品牌色       hover：border 变 strong       hover：饱和度上调
```

## 10. 不做什么（明确否定项）

- 不用 `backdrop-filter: blur` 任何变体
- 不用渐变背景
- 不用 `border-radius ≥ 10px`
- 不用 800 极粗字重
- 不引入 streamlit-extras 或自定义 React 组件
- 不动 `st.chat_input` 位置（Phase 7 rerun 循环教训）
- 不为了视觉一致而牺牲功能可读性（severity 色必须保持高识别度）
