# UniLife OS 设计系统

> 第二期重构 R8 阶段产物。当前代码以 `ui/styles.py` 中的 CSS token 为准。
> 起草时间：2026-04-25；R8 收尾同步：2026-04-26。

## 0. 设计目标与基调

**核心目标**：让 UniLife OS 在赛道里"第一眼不一样"——拥有现代消费级 AI 产品应有的**高级感（premium feel）**，而不是又一个紫色渐变 Streamlit 模板。

**风格基调**：高级平面设计为主，构成主义结构感为辅。

具体而言：
- **平面设计语言**为主：克制的色彩 / 精确的字体层级 / 大块负空间 / 强对比 / 几何块面 / 不依赖装饰元素。这是"高级感"的底层语法。
- **构成主义启发**为辅：保留它的"硬边、强分隔、不对称留白、底部强调线"等结构手法，让视觉有识别度，但**不教条**——不需要严格的红黑黄三色体系，不需要刻意的工业海报感。
- **温度保留**：底色用米色 off-white 而非冷白；按钮交互保留情绪反馈；emoji 在功能场景仍可使用。学生用户每天打开，纯黑白会显得冷峻。

### 高级感的来源（评判每个改动是否"高级"的清单）

1. **克制**：能用 3 个色就不用 5 个；能用一根分隔线就不用阴影。
2. **精致**：字体层级清晰（display ↔ body ≥ 2.4×），间距严格走 8px 网格。
3. **理性**：每个元素都有功能依据，没有"为了好看而加"的装饰。
4. **呼吸**：留白比内容更重要，密集编排是平价感的来源。
5. **稳定**：圆角统一、边框统一、按钮形状统一，避免视觉碎片化。

## 1. 色板（Color Tokens）

色板分两层：**品牌层**（决定整体气质）+ **语义层**（功能反馈）。

### 1.1 品牌层（用于 Header / 主按钮 / Tab 标记 / 链接）

```css
--color-bg-primary:  #FAF7F1   /* 米色 off-white，全局 body / .stApp */
--color-bg-surface:  #FFFFFF   /* 卡片 / Metric / Expander 底 */
--color-bg-emphasis: #2C1F14   /* 暖棕黑，主按钮 / 强强调 */
--color-bg-muted:    #F0EBE0   /* 二级背景 / 进度条轨道 */
--color-bg-recessed: #E2DCCD   /* 侧栏沙底 / 凹陷底 */
--color-bg-deep:     #ECE3D2   /* hero 外卡 / 看板分隔 panel 底 */
--color-bg-warm:     #FFFCF7   /* 带暖意的纯白 surface */

--color-text-primary: #2C1F14
--color-text-muted:   #7A6859
--color-text-inverse: #FAF7F1

--color-brand:        #D97757  /* Anthropic coral，品牌主色 */
--color-brand-soft:   #E8967A  /* 品牌主色 hover / 浅化变体 */
--color-brand-deep:   #B05F44  /* 深一档，用于图标 / focus */
```

> R8 收尾后品牌色从深酒红转为更暖的 Anthropic coral，用米色纸面和暖棕黑文字承接质感；不再使用紫色渐变模板。

### 1.2 语义层（severity / 功能性颜色）

```css
--color-severity-high:   #C5483F   /* 紧急告警 */
--color-severity-medium: #D9893F   /* 中级提醒 */
--color-severity-low:    #4F8A6E   /* 低优先 / 完成态 */

--color-data-1:          #2C1F14
--color-data-2:          #D97757
--color-data-3:          #B89476
```

> 品牌色与 severity-high 都偏红但有区分：品牌色 `#D97757` 用于"我是 UniLife"的身份标识和交互强调，severity-high `#C5483F` 用于"现在有事"的告警动作。两者同属暖色但职责不同。

### 1.3 边框

```css
--color-border-hairline: rgba(44, 31, 20, 0.10)   /* 默认 1px 分隔 */
--color-border-strong:   rgba(44, 31, 20, 0.40)   /* 强分隔 */
--color-border-focus:    var(--color-brand)       /* 输入框 focus */
```

## 2. 字体栈（Typography）

> V3.4.4 修订（2026-04-25）：移除 Inter / Geist 等 DesignPrompt 红线提到的"已审美疲劳"sans 家族；中文项目 PingFang SC 优先；display 衬线保留 Source Serif 4。

```css
--font-display: "Source Serif 4", "Noto Serif SC", "Songti SC", Georgia, serif;
--font-body:    "PingFang SC", "Hiragino Sans GB", "Helvetica Neue", "Microsoft YaHei", system-ui, -apple-system, sans-serif;
```

字重档位（V3.4.4 收敛到 3 档 + 1 个数字强调）：
- **800**（display 大字 + metric value 数字）— hero h1 / section h2 / dashboard h4 / metric value
- **600**（标题 / 按钮 / metric label uppercase）— sidebar h3 / alert h4 / button text
- **400**（正文 / caption / 链接） — 默认

> 原 §2 写"不使用 800"的红线在 V3.4.4 重写：display 衬线 Source Serif 4 在 800 字重下与中文衬线视觉重量一致，不属"用力过猛"。500 / 700 全部并入相邻档位避免散乱。

## 3. 字号尺度（Type Scale）

V3.4.4 字号阶 = 5 档常规 + 1 档 hero clamp + 1 档 micro + 1 档 metric 特例：

```css
--fs-hero:     clamp(2.4rem, 4.6vw, 3.6rem)  /* hero h1 唯一动态字号 */
--fs-display:  1.75rem  (28px)               /* dashboard 章节 h4 / 主区大标题 */
--fs-h2:       1.34rem  (21px)               /* section-heading h2 / alert-card h4 */
--fs-h3:       1.05rem  (17px)               /* sidebar 模块标题 (### 课程 / 财务) */
--fs-body:     0.95rem  (15px)               /* 正文 / 按钮 / metric label */
--fs-caption:  0.78rem  (12.5px)             /* caption / eyebrow */
--fs-micro:    0.68rem  (11px)               /* metric delta / metric note */
--fs-metric:   1.46rem  (23px)               /* sidebar metric value 窄列特例 */
```

字间距 token（V3.4.4 收敛到 3 档 + body 默认 0）：

```css
--ls-eyebrow:  0.14em   /* uppercase 大写小字 eyebrow / 按钮文本 */
--ls-display: -0.02em   /* display 大字微负 tracking（hero h1 / section h2 / metric value） */
--ls-caps:     0.06em   /* metric label / sidebar h3 等 uppercase 中字 */
```

行高 token（V3.4.4 收敛到 4 档）：

```css
--lh-tight:    1.0    /* hero h1 / section h2 大字 */
--lh-snug:     1.2    /* metric value / 中字标题 */
--lh-normal:   1.5    /* body */
--lh-relaxed:  1.62   /* hero 描述段长 paragraph */
```

**元素映射表**（散落 magic 值收敛到这一张表后，所有字体相关动作都查这里）：

| 元素 | font-family | font-size | font-weight | letter-spacing | line-height |
|---|---|---|---|---|---|
| hero h1 | display | hero | 800 | display | tight |
| section h2 | display | h2 | 800 | display | tight |
| dashboard h4 (主区) | display | display | 800 | display | snug |
| alert-card h4 | display | h2 | 600 | display | snug |
| sidebar metric value | display | metric | 800 | display | snug |
| sidebar metric label | body | caption | 600 | caps + uppercase | snug |
| main metric value | display | 1.72rem | 800 | display | snug |
| main metric label | body | caption | 600 | caps + uppercase | snug |
| metric delta / note | body | micro | 400 | 0 | snug |
| sidebar h3 模块标题 | body | h3 | 600 | caps + uppercase | (默认) |
| section / hero eyebrow | body | caption | 700 | eyebrow + uppercase | snug |
| body 正文 | body | body | 400 | 0 | normal |
| hero 描述段 | body | body | 400 | 0 | relaxed |
| caption | body | caption | 400 | 0 | normal |

## 4. 间距尺度（Spacing）

8px 网格，严格走基数：

```css
--space-1: 4px     /* 紧贴元素之间 */
--space-2: 8px     /* 内文行间 / 小元素间距 */
--space-3: 16px    /* 卡片内 padding */
--space-4: 24px    /* 卡片之间间距 */
--space-5: 32px    /* 章节间距 */
--space-6: 48px    /* 大区块分隔 */
--space-7: 64px    /* 章节标题前后 */
```

**留白原则**：宁多勿少。卡片之间用 `--space-4`，章节用 `--space-5`，大区块用 `--space-6`。

## 5. 圆角（Radius）

```css
--radius-none: 0px   /* Header / Tab 强调线 */
--radius-sm:   4px   /* 小控件 / 内嵌元素 */
--radius-md:   6px   /* 默认卡片 / Alert / Metric / Expander / 按钮 */
--radius-lg:   10px  /* 仅当真的需要"软"的元素，如 chat message / hero 外卡 */
```

> R8 最终允许 `10px` 作为大卡片上限；避免 12px+ 的大圆角。

## 6. 边框（Border）

```css
--border-hairline:  1px solid var(--color-border-hairline)
--border-strong:    2px solid var(--color-border-strong)
--border-severity:  4px solid <severity color>            /* Alert 卡片左强调条 */
--border-tab:       3px solid var(--color-brand)          /* Tab 选中底部 */
--border-focus:     2px solid var(--color-border-focus)   /* 输入框 focus 态 */
```

## 7. 阴影（Shadow）

默认使用克制拟态阴影，透明度上限控制在 0.10：

```css
--shadow-card:
  inset 0 1px 0 rgba(255,255,255,0.62),
  0 1px 2px rgba(44,31,20,0.07),
  0 6px 16px rgba(44,31,20,0.08);
--shadow-hover:
  inset 0 1px 0 rgba(255,255,255,0.68),
  0 3px 8px rgba(44,31,20,0.09),
  0 12px 24px rgba(44,31,20,0.09);
--shadow-inset:
  inset 0 1px 2px rgba(44,31,20,0.06),
  inset 0 0 0 1px rgba(44,31,20,0.04);
```

不用紫色 glow、糖果渐变阴影和高透明毛玻璃。

## 8. 组件视觉规范

### 8.1 Header

```text
After（米底 + 黑块 Header + 左竖品牌色条）
┃                              ↑ coral 品牌色状态锚点 / 数字面板分隔
┃ 🎓 UniLife OS                 display 32px / 700，米色字
┃ 你的大学生活智能操作系统      body 15.2px / 400，米色 60% 透明
┃
```

- 背景使用 `--color-bg-deep` 外卡 + `--color-bg-warm` 内卡，避免纯黑大块压住内容
- 圆角 0
- 内 padding：上下 `--space-3`，左右 `--space-4`
- 左侧 4px 品牌色竖条（构成主义结构标记，但克制为 4px 而非 5px）

### 8.2 Alert 卡片

```text
┃▎🔴 预算告警                        ← 标题 H3 size，severity 色
┃▎本月已花 ¥1900 / ¥2000，剩 5 天   ← body
┃▎  💡 建议日限 ¥20                  ← caption muted
┃▎  [标为已读]                       ← 次按钮
```

- 白底 `--color-bg-surface`
- 左侧 4px severity 色强调条（`--border-severity`）
- 圆角 2px
- 上下 `--space-3` padding，左 `--space-4` padding（避开强调条）
- 标题字号 H3，严重度色；正文 body 主色；caption muted 色

### 8.3 Metric（侧边栏指标卡）

```text
┌─────────────┐
│ 步数        │  ← caption size，muted
│ 8,234       │  ← H2 size，700 重，主色
│ 目标 10,000 │  ← caption muted
└─────────────┘
```

- 白底 + `--border-hairline`
- 圆角 2px
- padding `--space-3`
- 数字用 `--fs-h2` + 700，是 Metric 的视觉主体

### 8.4 Tab 导航

```text
💬 AI 对话    📊 数据看板
━━━━━━━━━━

← 选中态：字重 700 + 底部 3px 品牌色横条 + 字色 primary
← 未选态：字重 500 + 字色 muted + 无装饰
```

- 不要胶囊背景
- 不要圆角
- 仅靠字重 + 底部红条区分选中

### 8.5 按钮三级

```text
主按钮（保存/记录）    次按钮（标为已读）        危险按钮（重置）
┏━━━━━━━━━┓             ┌───────────┐               ┏━━━━━━━━━━━┓
┃ 📝 记录  ┃             │  标为已读  │              ┃ 🧹 重置   ┃
┗━━━━━━━━━┛             └───────────┘               ┗━━━━━━━━━━━┛
背景 emphasis (#2C1F14)  透明 + hairline border       背景 severity-high (#C5483F)
字 inverse (米)           字 primary                    字白
圆角 4px                  圆角 4px                      圆角 4px
hover：背景变品牌色       hover：border 变 strong       hover：饱和度上调
```

## 10. 不做什么（明确否定项）

- 不用 `backdrop-filter: blur` 任何变体
- 不用渐变背景
- 不用 `border-radius ≥ 10px`
- ~~不用 800 极粗字重~~ → V3.4.4 修订：display 衬线 800 字重视觉重量与中文衬线匹配，保留作为 display / metric value 的数字强调字重（参见 §2 字重档位）
- 不引入 streamlit-extras 或自定义 React 组件
- 不动 `st.chat_input` 位置（Phase 7 rerun 循环教训）
- 不为了视觉一致而牺牲功能可读性（severity 色必须保持高识别度）
- 不用 Inter / Roboto / Arial / Geist / Fraunces 等 DesignPrompt 红线提到的"已审美疲劳"sans 家族（V3.4.4 已从 `--font-body` 移除 Inter）
