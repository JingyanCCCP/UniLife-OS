## 0. 给接手 AI 的交接协议

本文档的首要读者是接手项目的 AI 编程助手。按下面这张流程卡执行，不要从头重新规划。

### 0.1 开工 5 分钟必做

1. 运行 `cd /home/jingyan/UniLife-OS && git status --short`，确认工作区干净或记下当前脏文件。
2. 打开 `docs/开发记录.md`，定位「当前激活任务卡」和「今日变更记录」。
3. 回到本文档第 5 节「任务卡队列」，找到当前激活卡的 `状态：激活`。
4. 只做当前激活卡里「允许改动的文件」列出的文件，不顺手重构其他地方。
5. 完成后按 0.3 的收尾清单更新文档。

### 0.2 阶段切换规则

- 每张任务卡都有独立的入口条件、时间预算和验收命令。
- 只有当前卡的验收命令全部通过，才允许把下一张卡从 `状态：排队` 切到 `状态：激活`。
- 禁止一次激活两张卡。禁止跨卡并行修改。
- 切换任务卡时必须在 `docs/开发记录.md` 追加一条「阶段切换」记录。

### 0.3 每轮开发结束必做

- 运行 `git status --short`，确认改动面与当前任务卡匹配。
- 运行当前任务卡的全部验收命令。
- 在 `docs/开发记录.md` 追加一条当日记录（模板见文末）。
- 若任务卡完成，在本文档对应卡片里把 `状态` 改为 `完成`，下一张卡改为 `激活`。
- 若当前方向与规划不一致，先更新本文档再继续。

### 0.4 触发红线即停（不要尝试绕过）

- 任何改动让 `streamlit run app.py` 启动失败 → 立即回滚、停止。
- 任何改动让现有 24 个工具之一无法执行 → 立即回滚、停止。
- 任何改动让 PWA `manifest.json` / `sw.js` 路径失效 → 立即回滚、停止。
- 发现 `.env` 或 `data/user_data.json` 被纳入改动面 → 立即回滚、停止。

红线触发时，在 `docs/开发记录.md` 追加「红线事件」记录，等待用户指令。

### 0.5 如果完全不确定下一步做什么

按这个顺序兜底：

1. 阅读当前激活卡的「目标」「具体任务」「验收命令」三节。
2. 若仍不确定，只做当前卡中最小的一个子任务（通常是第一条），验证跑通，然后停下来等反馈。
3. 不要为了"推进阶段"而大改代码。当前阶段没完就停在当前阶段。

## 1. 项目叙事与评分映射

### 1.1 参赛定位

UniLife OS 是面向大学生日常生活的个人 Agent 操作系统。它持续理解学生状态，主动发现风险，并通过工具完成真实操作。

核心闭环：

1. **状态感知**：统一读取课程、财务、健康、待办、旅行等生活状态。
2. **工具行动**：通过 24 个结构化工具真实查询、记录、修改用户数据。
3. **主动关怀**：根据状态变化生成预算、考试、健康、待办、旅行提醒。
4. **可视反馈**：对话回复、侧边栏、数据看板同步反映状态变化。

### 1.2 评分标准映射

| 评分维度（权重）| 规划案对应交付 | 承接阶段 |
|---|---|---|
| 创新性 | 主动关怀引擎 + 结构化工具调用可视化 + 动态 context 注入 | R2, R3 |
| 效率 | 上下文裁剪、工具按需调用、mock 动态日期、原子写入 | R1, R3, R5 |
| 鲁棒性 | pytest 覆盖核心链路 + 工具异常兜底 + API/网络异常体验 | R1, R5 |
| 实用价值 | 5 模块 24 工具 + 主动关怀 + 演示重置 | R2, R3 |
| 人机交互 | 对话 + 看板双路径 + 今日快报 + 工具调用展示 + PWA | R4 |
| 展示效果 | 5 分钟演示脚本稳定跑通 + seed 一键重置 | R4, R6 |

### 2.2 当前主要问题（按优先级）

1. **mock 日期硬编码**：`2026-02-20`、`2026-03-01` 等已过期 2 个月以上，现在打开应用直接露馅。
2. **职责混乱**：`mock_data.py` 同时扮演 seed、持久化合并、context 拼装三种角色，改动难度大。
3. **工具单文件**：`modules/tools.py` 1261 行，schema + 24 个执行函数 + 路由全塞在一起。
4. **缺少测试**：核心链路（日期计算、预算统计、工具调用）没有回归保障。
5. **主动关怀是散文式**：`get_alerts()` 是函数式规则，没有事件结构、去重、节流，也没写入持久层。

### 2.3 当前保留的设计（不要动）

- Streamlit + DeepSeek function calling 主链路
- JSON 增量覆盖持久化（`data/user_data.json`）
- 侧边栏 / AI 对话 Tab / 数据看板 Tab 的三视图结构
- Toast 延迟显示机制 (`_toast_and_rerun`)
