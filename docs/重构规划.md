## 0. 给接手 AI 的交接协议

### 0.1 5 分钟开工检查

1. 读完本节 0.1 / 0.2 / 0.3 三段。
2. 跳到第 4 节「任务卡队列」，找到状态 `激活` 的卡。其它卡先不读。
3. 读 `docs/开发记录.md` 末尾最近一条记录，理解上一位接手 AI 在哪里收笔。
4. 运行 `git status --short`，确认工作区状态。
5. 读当前任务卡的「允许改动」「禁止改动」「验收命令」三个字段，**只动允许列表里的文件**。

### 0.2 推进单张任务卡的标准流程

```
读卡片 → 写代码 → 跑验收命令（4 项必须全过）→ 更新开发记录 → 把卡片状态由「激活」改为「完成」→ 把下一张「排队」改为「激活」
```

任何一步卡住超过 30 分钟，先停下来汇报，不要硬怼。

### 0.3 收尾清单（每张卡完成时）

- [ ] `git status --short` 已查看，禁区文件保持干净
- [ ] 当前任务卡的 4 项验收命令全部跑通
- [ ] `docs/开发记录.md` 已追加本轮记录（用第 8 节模板）
- [ ] 任务卡状态已切换（完成 → 排队的下一张激活）
- [ ] 本文档第 4 节里，对应卡片的状态字段已同步修改

### 0.4 触发红线即停（不要尝试绕过）

- 任何改动让 `streamlit run app.py` 启动失败 → 立即回滚、停止
- 任何改动让现有 28 个工具之一无法执行 → 立即回滚、停止
- 任何改动让 PWA `manifest.json` / `sw.js` 路径失效 → 立即回滚、停止
- 发现 `.env` 或 `data/user_data.json` 被纳入改动面 → 立即回滚、停止

红线触发时，在开发记录里写「⚠️ 红线事件」记录，等待用户指令。

### 0.5 兜底（卡片不够清楚或拿不准下一步）

1. 不要凭感觉扩展改动范围。
2. 在 `docs/开发记录.md` 末尾写一条「⚠️ 阻塞」记录，说明：当前卡 ID、阻塞点、需要的额外信息或决策。
3. 停下等反馈。只做当前卡里最小的子任务（通常是第一条），跑通了就停。

## 1. 项目叙事与评分映射

UniLife OS 是面向大学生日常生活的个人 Agent 操作系统。它持续理解学生状态，主动发现风险，并通过工具完成真实操作。

核心闭环：
1. **状态感知**：统一读取课程 / 财务 / 健康 / 待办 / 旅行五大模块。
2. **工具行动**：通过 28 个结构化工具（24 文本 + 4 多模态视觉）真实查询、记录、修改用户数据。
3. **主动关怀**：根据状态变化生成预算、考试、健康、待办、旅行提醒。
4. **可视反馈**：对话回复、侧边栏、数据看板同步反映状态变化。

| 评分维度 | 本规划主要交付 | 承接阶段 |
|---|---|---|
| 创新性 | 主动关怀引擎 + 双模型协同（DeepSeek 决策 + 豆包视觉）+ 链式工具 | R2 / R3 / R7 |
| 效率 | 上下文裁剪、工具按需调用、mock 动态日期、原子写入 | R1 / R3 / R5 |
| 鲁棒性 | pytest 71 项 + 工具异常兜底 + API/网络异常体验 | R1 / R5 / R7 / R8 |
| 实用价值 | 5 模块 28 工具 + 主动关怀 + 演示重置 + 拍照入数据 | R2 / R3 / R7 |
| 人机交互 | 对话 + 看板双路径 + 主动关怀卡片 + PWA + 多模态 + 构成主义视觉 | R4 / R7 / R8 |
| 展示效果 | 5 分钟演示脚本 + seed 一键重置 + 真机走查截图 | R4 / R6 / R8 |

## 3. 目标架构与多模态调用链

### 3.1 多模态调用链路（R7 落地）

```
用户输入：文本 / 文本 + 图片
    ↓
ui/chat.py — chat_input + 📷 上传图片 expander（Pillow 压到 ≤1024px）
    ↓
DeepSeek V4-Flash 决策层（含 image flag → 倾向调 vision_* 工具）
    ↓
agent/executor — 工具分发
    ├── 文本 24 工具 → modules/persistence
    └── 视觉 4 工具 → modules/vision（豆包 OCR 结构化抽取） → 链式调下游
    ↓
proactive.engine.scan_safely() — 工具执行后扫描主动关怀事件
    ↓
状态更新 → UI / 看板 / 侧边栏同步
```

### 3.2 双模型分工

| 模型 | 职责 | 调用方式 |
|---|---|---|
| **DeepSeek V4-Flash** (`deepseek-v4-flash`) | 决策 + 工具选择 + 自然语言回复 | OpenAI SDK，function calling |
| **豆包 vision** (`doubao-seed-1-6-vision-250815`，需通过火山方舟 endpoint ID) | 图像识别 + 结构化抽取 | OpenAI 兼容接口，content blocks 含 image_url |

两者都通过 OpenAI SDK 调用，只是 base_url 不同：

- DeepSeek：`https://api.deepseek.com/v1`
- 豆包：`https://ark.cn-beijing.volces.com/api/v3`（注意：无 `.cn` 后缀，路径是 `/api/v3`，旧文档里的 `/api/v1` 已废）

### 3.3 视觉风格目标（R8 落地）

「**构成主义启发的现代极简**」：硬边、强对比、克制色板、几何块面、强分隔线。

| 维度 | 旧（紫渐变模板） | 新（R8 收敛） |
|---|---|---|
| 主色 | 紫渐变 `#667eea → #764ba2` | 米色 off-white `#FAF7F1` 底 + 暖棕黑 `#2C1F14` + coral `#D97757` |
| 圆角 | 10px 圆润 | 0-4px 硬边 |
| 阴影 | 多处毛玻璃 | 几乎不用；用 1px hairline border + 大块色组织层次 |
| 字体 | Streamlit 默认 | Heavy sans-serif headlines + Regular body |
| 排版 | 对称居中 | 不对称 grid，左对齐为主 |
| 主动关怀卡片 | 三色渐变填充 | 白底 + 4-5px severity 色左边框 |

详见 `docs/设计系统.md`。
